A list of results is the least interesting page on this site — so each line here carries the context that makes it mean something. If you only read one entry, read the Create Award.

The one I'd point at

Create Award, Nationals 2026.

Every other result on this page measures how a robot performed on one particular day. The Create Award measures whether the reasoning that produced the robot holds up when someone reads it back to you.

It's the award for engineering process — documentation, decisions, evidence, iteration. Which means it's the only line here that would still be true if the robot had broken in the first match. That's why it's first.

Two years earlier I thought a missed autonomous run was a software bug. This award is what that mistake turned into.
